# mangalib-dl

Скачивает мангу с [MangaLib](https://mangalib.me) в zip/cbz-архивы с картинками jpg/png.
Такие архивы — обычный формат распространения манги. Их понимают Kindle Comic Converter (KCC),
Calibre, Komga, Kavita и большинство читалок. Конвертации в EPUB здесь нет: её делает KCC или аналог.

Один бинарник, два режима:

- **веб-интерфейс** на `localhost`: поиск, выбор перевода и глав, очередь загрузок, скачивание готовых архивов из браузера;
- **CLI**: `search`, `info`, `download`.

## Сборка

Нужен Go 1.26+.

```sh
git clone git@github.com:koshiex/mangalib-dl.git
cd mangalib-dl
go build -o mangalib-dl ./cmd/mangalib-dl
```

## Веб-интерфейс

```sh
./mangalib-dl serve                 # http://127.0.0.1:8080, архивы в ./downloads
./mangalib-dl serve -addr 127.0.0.1:9000 -out ~/Manga
```

В поиске можно ввести название или вставить ссылку на тайтл (`https://mangalib.me/ru/manga/3445--houseki-no-kuni`).
На странице тайтла выберите перевод, способ нарезки архивов, формат и главы.
Shift+клик выделяет диапазон глав, чекбокс тома выделяет весь том.
Загрузки выполняются по очереди, по одной. Готовые файлы можно скачать из панели «Загрузки»,
они также лежат в каталоге `-out`.

Сервер слушает только `127.0.0.1`. Он отклоняет запросы с чужим `Host` (защита от DNS rebinding)
и cross-origin POST, поэтому посторонний сайт в браузере не может запустить загрузку.

## CLI

```sh
./mangalib-dl search "страна самоцветов"
./mangalib-dl info 3445--houseki-no-kuni            # главы, тома и id переводов
./mangalib-dl download 3445--houseki-no-kuni        # всё, по архиву на том
./mangalib-dl download https://mangalib.me/ru/manga/3445--houseki-no-kuni -volumes 1-3 -format cbz
./mangalib-dl download 3445--houseki-no-kuni -chapters 1-10,12 -mode chapter
```

| Флаг | По умолчанию | Значение |
|---|---|---|
| `-out` | `downloads` | каталог для архивов |
| `-mode` | `volume` | `volume` — архив на том, `chapter` — на главу, `single` — один архив |
| `-format` | `zip` | `zip` или `cbz` (это одинаковые zip-файлы, отличается расширение) |
| `-chapters` | все | номера глав: `1-10,12,20.5,30-` |
| `-volumes` | все | номера томов: `1-3` |
| `-branch` | `-1` (авто) | id перевода из `info`; `0` — перевод по умолчанию |
| `-workers` | `4` | параллельных загрузок страниц |

Если главы нет в выбранном переводе, она берётся из другого, программа выводит предупреждение.
В режиме «авто» выбирается перевод, в котором больше всего глав.

Готовые архивы пропускаются, поэтому прерванную загрузку можно просто запустить снова.
Архив пишется во временный файл и переименовывается только после успешного завершения,
поэтому битых архивов под финальным именем не бывает.

### Авторизация

Некоторые тайтлы (часть 18+) API отдаёт только авторизованным пользователям.
Для них передайте Bearer-токен MangaLib через переменную окружения:

```sh
export MANGALIB_TOKEN=...
./mangalib-dl serve
```

Токен уходит только в API MangaLib и не пишется в логи.

## Структура архивов

```
downloads/Страна самоцветов/
  Страна самоцветов - Vol.01.zip
    ComicInfo.xml
    Vol.01 Ch.001 - Фосфофиллит/001.jpg
    Vol.01 Ch.001 - Фосфофиллит/002.jpg
    Vol.01 Ch.002 - Киноварь/001.jpg
  Страна самоцветов - Vol.02 (Ch.008-010).zip   ← том скачан не целиком
```

- В режиме `chapter` страницы лежат в корне архива без подпапок.
- Номера дополняются нулями (`Vol.01`, `Ch.005`, `003.jpg`), чтобы файлы сортировались правильно.
- Папки глав KCC использует как оглавление EPUB.
- `ComicInfo.xml` содержит название, том, номер главы, авторов, жанры и описание. Для японской манги стоит
  `Manga=YesAndRightToLeft`.
- JPEG и PNG кладутся как есть. WebP, GIF и BMP конвертируются в PNG.
- Имена файлов в zip — UTF-8 с соответствующим флагом. Системный `/usr/bin/unzip` на macOS показывает
  их кракозябрами, но Finder, `bsdtar`, Python и KCC читают правильно.

Пример конвертации в KCC: `kcc-c2e -p KPW5 -f EPUB "Страна самоцветов - Vol.01.zip"`.

## Как это работает

- API: `https://api.cdnlibs.org/api` (поиск `/manga?q=`, тайтл `/manga/{slug}`, главы `/manga/{slug}/chapters`,
  страницы `/manga/{slug}/chapter?volume=&number=&branch_id=`, серверы картинок `/constants?fields[]=imageServers`).
  Без заголовка `Referer: https://mangalib.me/` API и CDN отвечают 403.
- Лимит API — 100 запросов в минуту. Клиент выдерживает интервал 650 мс между запросами к API
  и повторяет запросы при 429/5xx с учётом `Retry-After`.
- Серверы картинок перебираются по порядку: `main`, `secondary`, `download`, `compress`.
  Первый рабочий запоминается. `main` отдаёт оригиналы, но из части сетей отвечает 403;
  тогда картинки идут с `download`/`compress` в JPEG.

## Ограничения

- Лицензированные тайтлы на MangaLib часто без глав: их удаляют по требованию правообладателя.
- Платные и удалённые главы API отдаёт без страниц. Такой архив пропускается с предупреждением,
  остальные архивы скачиваются.
- API неофициальный и может поменяться.

Инструмент для личного использования. Уважайте переводчиков и правообладателей.
